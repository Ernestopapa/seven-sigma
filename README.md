# Seven Sigma (SIGMA)

Seven Sigma is a collection of 777 Sigma Node NFTs on BSC mainnet. Minting is gated by Binance Agent ID, so only Agent ID holders can mint the free nodes. The art comes in 7 variants, 111 of each.

Contract: [0x9281740a566901aFBA3E566e505e1896bE176ff8](https://bscscan.com/address/0x9281740a566901aFBA3E566e505e1896bE176ff8)

Supply: 777 total. 150 free and 627 paid. The free mint is 1 per wallet and has sold out. Paid minting is open at 0.00042 BNB ($0.30) per mint.

Minted: 167 as of 15 Nov 2026, including 17 paid mints. See the live count on BscScan: https://bscscan.com/token/0x9281740a566901aFBA3E566e505e1896bE176ff8

No floor price, no returns, and no token promised.
